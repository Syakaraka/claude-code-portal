⚠ 首次使用 · 必须先安装内部 CA 证书 Windows

Code Server 的 Claude Code 扩展依赖浏览器 Service Worker。Chrome 对 Service Worker 的 fetch 严格校验证书，self-signed cert 会被拒（即使主页面 accept 了警告，扩展也无法加载）。Portal 用内部 CA 签发用户证书，你只需把 这张 CA 装到 Windows 信任库一次。证书文件 claude-code-portal-ca.crt 内容是 PEM 文本（后缀名是给 Windows 关联"证书"图标用的）。

安装步骤（Windows 10 / 11）

  1. 下载 → claude-code-portal-ca.crt 浏览器右上角出现下载文件
  2. 双击下载好的 claude-code-portal-ca.crt 若弹"打开文件 - 安全警告"（下载自互联网）→ 直接"打开"即可
  3. 弹出"证书"对话框 → 点右下角 "安装证书(C)…" 按钮 ⚠ 不是点"确定"——点"确定"只是关闭对话框，不会安装
  4. "证书导入向导" → 选 "当前用户(U)"（无需管理员权限）→ 下一步
  5. 选 "将所有的证书都放入下列存储(P)" → 点"浏览(B)…" → 选 "受信任的根证书颁发机构" → 确定 → 下一步 ⚠ 这里选错 store 是最常见的失败原因——必须选"受信任的根证书颁发机构"，不是"个人"也不是"中间证书颁发机构"
  6. "正在完成证书导入向导" → 点 "完成"
  7. 关键 → 弹出"安全性警告"对话框： "Windows 无法验证该证书是否真的来自 'Claude Code Portal Internal CA'。 您是否要安装此证书？"
    → 点 "是(Y)"（这是自签 CA 必然会出现的提示，不是错误） ⚠ 点"否"等于没装，跟没做这一步一样
  8. "导入成功"提示 → 确定；前面的"证书"对话框也可关掉
  9. 关键 → 必须完全退出 Chrome再打开。 Chrome 后台进程（service worker / GPU / network）会缓存 trust store 数小时，单纯刷新页面或关窗口不生效。三种退出方法任选其一：
    ① 任务栏右键 Chrome 图标 → "关闭所有窗口" 或 "退出 Chrome"
    ② 地址栏输入 chrome://quit 回车
    ③ PowerShell 里执行 taskkill /F /IM chrome.exe
    ⚠ Ctrl+Shift+Q 是 QQ 的截图快捷键，不是 Chrome 的
  10. 重新打开 Chrome 访问 Code Server → 不应该再看到"您的连接不是私密连接"警告，直接进入

验证是否装上：
方法 1：Win+R → 输入 certmgr.msc → 受信任的根证书颁发机构 → 证书 → 找 "Claude Code Portal Internal CA"。
方法 2：PowerShell 执行 Get-ChildItem Cert:\CurrentUser\Root | Where-Object { $_.Subject -like '*Claude*' } 应返回一条 Issuer / Subject 都是 Claude Code Portal Internal CA 的记录。

浏览器兼容性：
✓ Chrome（推荐）、Edge——两者共用 Windows 信任库， 给 Chrome 装一份 Edge 自动生效，反之亦然。
✗ Firefox：Firefox 用自己的证书库，不读 Windows 根证书。 需要打开 Firefox → 设置 → 隐私与安全 → 证书 → 查看证书 → 证书颁发机构 → 导入 → 选 claude-code-portal-ca.crt → 勾选 "信任由此证书颁发机构标识的网站"。
✗ iOS / iPadOS Safari：苹果不允许向系统 trust store 装用户 CA， 本方案对 iOS 不可用，需要走公网 CA 签发的 cert（不在本部署范围内）。
